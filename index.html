✨ کامپوننت‌ها و الگوهای تعاملی

با کلیک روی نام ماه یا سال می‌توانید فوراً بین ماه‌ها و دهه (Decade) جابجا شوید. در موبایل تقویم به Bottom Sheet تبدیل می‌شود.

تقویم شمسی + تعویض تقویم (Switcher)

سوئیچر مستقیم بین شمسی، میلادی و قمری. روی ماه یا سال کلیک کنید تا نمای انتخاب ماه/دهه باز شود.

—

انتخاب بازه تاریخی (Range Mode)

هایلایت پیوسته روزهای بین شروع و پایان، گوشه‌های گرد ابتدا و انتها و نشانگر روزهای رنج.

—

انتخاب چند تاریخ (Multiple Mode)

انتخاب چند روز با انیمیشن Pop اختصاصی و مدیریت خودکار آرایه تاریخ‌ها.

—

تاریخ و ساعت (Time Picker Stepper)

انتخاب روز همراه با استپر دکمه‌های + و − برای ساعت و دقیقه، و تغییر حالت ۲۴ یا ۱۲ ساعته.

—

حالت توکار (Inline Mode)

تقویم تعبیه‌شده مستقیم در بدنه کارت بدون نیاز به پاپ‌آپ، ریسپانسیو و لمس‌پذیر.

—

نمای دو ماهه (Multi-Month)

نمایش همزمان ۲ ماه در کنار هم برای دسکتاپ و تبلت با ناوبری یکپارچه.

—

محدودیت تاریخ و تعطیلات

فقط بازه ۱۰ روز آینده مجاز است؛ روزهای جمعه خط‌خورده و غیرفعال هستند.

—

💻 استفاده آسان در فریم‌ورک‌ها

کامپوننت React:

import { DatePicker } from 'my-datepicker-react';

export function App() {
  const [val, setVal] = useState('1403/07/14');
  return (
    <DatePicker
      calendar="jalali"
      calendarSwitcher={true}
      theme="ios"
      design="rounded"
      mode="range"
      pattern="l j F Y"
      value={val}
      onChange={(newVal) => setVal(newVal)}
    />
  );
}

موتور SmartDate در TypeScript:

import { SmartDate } from 'my-datepicker-core';

const sd = SmartDate.now();
console.log(sd.getShYear()); // 1405
console.log(sd.format('l j F Y')); // دوشنبه ۱۴ مهر ۱۴۰۵
console.log(sd.toGregorian()); // [2026, 10, 6]
console.log(sd.isLeap()); // false
const nextMonth = sd.addMonths(1);
