✨ کامپوننت‌ها و الگوهای تعاملی

با کلیک روی نام ماه یا سال می‌توانید فوراً بین ماه‌ها و دهه (Decade) جابجا شوید. در موبایل تقویم به Bottom Sheet تبدیل می‌شود.

تقویم شمسی + تعویض تقویم (Switcher)

سوئیچر مستقیم بین شمسی، میلادی و قمری. روی ماه یا سال کلیک کنید تا نمای انتخاب ماه/دهه باز شود.

—

انتخاب بازه تاریخی (Range Mode)

هایلایت پیوسته روزهای بین شروع و پایان، گوشه‌های گرد ابتدا و انتها و نشانگر روزهای رنج.

—

انتخاب چند تاریخ (Multiple Mode)

انتخاب چند روز با انیمیشن Pop اختصاصی و مدیریت خودکار آرایه تاریخ‌ها.

—

تاریخ و ساعت (Time Picker Stepper)

انتخاب روز همراه با استپر دکمه‌های + و − برای ساعت و دقیقه، و تغییر حالت ۲۴ یا ۱۲ ساعته.

—

حالت توکار (Inline Mode)

تقویم تعبیه‌شده مستقیم در بدنه کارت بدون نیاز به پاپ‌آپ، ریسپانسیو و لمس‌پذیر.

—

نمای دو ماهه (Multi-Month)

نمایش همزمان ۲ ماه در کنار هم برای دسکتاپ و تبلت با ناوبری یکپارچه.

—

محدودیت تاریخ و تعطیلات

فقط بازه ۱۰ روز آینده مجاز است؛ روزهای جمعه خط‌خورده و غیرفعال هستند.

  const dp = new DatePicker('#datepicker', {

کامپوننت استندالون Angular (سازگار با Reactive Forms): 
import { Component, ElementRef, ViewChild, AfterViewInit, OnDestroy, forwardRef } from '@angular/core';
import { ControlValueAccessor, NG_VALUE_ACCESSOR, FormsModule } from '@angular/forms';
import { DatePicker, DatePickerOptions } from 'my-datepicker-core';

@Component({
  selector: 'app-date-picker',
  standalone: true,
  imports: [FormsModule],
  template: `
    <div class="dp-wrapper" dir="rtl">
      <div #container></div>
    </div>
  `,
  providers: [
    {
      provide: NG_VALUE_ACCESSOR,
      useExisting: forwardRef(() => AppDatePickerComponent),
      multi: true
    }
  ]
})
export class AppDatePickerComponent implements AfterViewInit, OnDestroy, ControlValueAccessor {
  @ViewChild('container') containerRef!: ElementRef<HTMLDivElement>;
  private picker!: DatePicker;
  private onChange: (val: any) => void = () => {};
  private onTouched: () => void = () => {};

  ngAfterViewInit(): void {
    this.picker = new DatePicker(this.containerRef.nativeElement, {
      calendar: 'jalali',
      calendarSwitcher: true,
      pattern: 'l j F Y',
      theme: 'material',
      design: 'rounded'
    });

    this.picker.on('change', ({ value }) => {
      this.onChange(value);
      this.onTouched();
    });
  }

  writeValue(value: any): void {
    if (this.picker) {
      if (value) this.picker.setValue(value);
      else this.picker.clear();
    }
  }

  registerOnChange(fn: any): void { this.onChange = fn; }
  registerOnTouched(fn: any): void { this.onTouched = fn; }

  ngOnDestroy(): void {
    if (this.picker) this.picker.destroy();
  }
}
